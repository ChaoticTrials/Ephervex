# Interface tour

These captures show Ephervex with synthetic sample data. The images follow the
site's color mode, so switch it to see the matching Ephervex theme. Every
captured screen is on the [screenshots page](/screenshots).

Ephervex is not affiliated with or endorsed by Mojang or Microsoft.

## The window

The left navigation has five pages: Instances, Servers, Running, Activity, and
Settings. The right side shows details and actions for the selected item.

<ThemeScreenshot state="instances-overview" alt="Ephervex instance list" />

Each card shows the instance's icon or loader, a favorite star, its group, the
Minecraft version, how many managed mods it has, where it came from, whether
its storage is temporary or persistent, and its state. Search, filters, and
groups narrow a long list; see
[Instances](./instances.mdx#search-filter-and-sort-instances).

<ThemeScreenshot state="instances-overview" region="client-card" alt="An instance card" />

## Creating and importing

Create an instance by choosing an exact Minecraft release, a loader (Vanilla,
Forge, or NeoForge), and a loader version.

<ThemeScreenshot state="create-instance-dialog" alt="The create instance dialog" />

Import a Modrinth or CurseForge pack from a file, a link, or by dropping it on
the window. The dialog shows what the pack contains before anything is
installed. Optional files stay off unless you choose them.

<ThemeScreenshot state="import-modpack-ready" alt="A modpack ready to import" />

Some CurseForge authors disable third-party downloads. Ephervex shows the
blocked file with an **Open in Browser** action so you can download it manually.

<ThemeScreenshot state="import-modpack-manual-download" region="blocked-file" alt="A blocked CurseForge file with an Open in Browser action" />

While an import runs, the instance appears as a card with progress. Activity
shows the current operation and recent results while Ephervex stays open.

<ThemeScreenshot state="import-modpack-running" alt="An import in progress" />

See [Import Modpacks](./import-modpacks.mdx) for archive and link imports,
optional files, CurseForge access, and manual downloads.

## Mods

The Mods surface lists every mod of an instance and marks where each came from:
the pack, a dependency, your own addition, or a jar you placed by hand. The
catalog next to it only offers versions that fit the instance's exact Minecraft
version and loader.

<ThemeScreenshot state="client-mods" alt="Managed mods and the mod catalog" />

Turning a mod off shows what depends on it first.

<ThemeScreenshot state="mod-impact" alt="What turning a mod off affects" />

When a problem appears with a large mod set, mod isolation narrows it down by
enabling and disabling groups of mods between test launches.

<ThemeScreenshot state="mod-isolation-round" alt="A mod isolation round" />

See [Mods](./mods.mdx) for installation, switches, version changes,
dependencies, and file repair.
The [Mod Isolation guide](./mod-isolation.mdx) walks through each test round.

## Servers

A server can stand alone or be linked to a client instance. The server page
shows its address and state and offers start, stop, restart, and console
access.

<ThemeScreenshot state="servers-overview" alt="Ephervex server list" />

<ThemeScreenshot state="server-console" alt="The server console" />

The properties page has typed fields for the common settings and shows the
state of the Minecraft EULA. The server's **Settings** holds its Java, memory,
and JVM arguments. The workspace header shows the host's Java and its status;
select it to open **Settings**.

<ThemeScreenshot state="server-properties" alt="Server properties" />

A Forge or NeoForge server's **Mods** page can also search the catalog,
leaving out client-only mods.

<ThemeScreenshot state="server-mods" alt="A server's mods and a catalog search" />

See [Servers](./servers.mdx) for creation, EULA consent, network settings,
console controls, linked client launches, and recovery.

## Running and activity

Running lists the client instances and servers Ephervex currently supervises.
You can open their logs, stop a game, or open a server console from this page.

<ThemeScreenshot state="running-page" alt="A running client instance and server with process controls" />

Activity shows running, queued, completed, failed, and canceled operations.
You can cancel work that is still running or queued. Activity is cleared when
Ephervex exits.

<ThemeScreenshot state="activity-import-in-progress" alt="Activity with an import in progress and recent operation results" />

## When something goes wrong

The live log can filter by level and search. Crash reports are listed beside
it.

<ThemeScreenshot state="client-logs-live" alt="The live game log" />

Diagnostics checks a host for known problems and shows a preview of any fix.
Nothing changes until you apply it.

<ThemeScreenshot state="client-diagnostics-result" alt="A diagnosis with problems found" />

See [Diagnostics](./diagnostics.mdx) for logs, crash reports, fix previews,
and local bundles.

Snapshots keep a restorable copy of an instance's state.

<ThemeScreenshot state="snapshots" alt="Snapshots of an instance" />

See [Snapshots](./snapshots.mdx) to capture, restore, rename, and delete local
saved states.

## Keyboard and accessibility

Buttons, switches, filter chips, and navigation entries take keyboard focus
with Tab and show a focus ring. Enter or Space activates the focused control.
Sliders move one step at a time with the arrow keys, by ten steps with Page Up
and Page Down, and to either end with Home and End. Icon-only buttons show a
tooltip naming their action. A disabled button explains on hover why it is
unavailable, and keyboard focus skips it.
