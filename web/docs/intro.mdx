# Ephervex

Ephervex is a Linux Minecraft launcher and developer tool for disposable
bug-reproduction environments. Create an instance with exact Minecraft and
loader versions, reproduce a problem, and discard the environment when you
are done. Keep an instance persistent when you need to return to it.

The desktop application and command-line interface use the same instance and
server storage. Shared downloads, game assets, libraries, and managed Java
runtimes can be reused across environments.

These **v1** docs cover pre-v1 releases and the v1 release series.

## What you can do

- Create Vanilla, Forge, and NeoForge instances with exact versions.
- Import Modrinth and CurseForge packs, review optional files, and resolve
  files that need a manual download.
- Browse mods, change individual mod versions, and enable, disable, or remove
  mods with dependency checks.
- Use mod isolation to narrow down which mods are involved in a failure.
- Create standalone or linked servers, edit server properties, and use the
  server console.
- Inspect logs, crash reports, and diagnostics, and take local snapshots
  before changes.

Start with [Getting Started](./getting-started.mdx), then read the
[interface tour](./interface-tour.mdx).

## Supported scope

Ephervex supports Linux on x86_64 and aarch64. On x86_64, it supports Minecraft
**release versions 1.12.2 and newer** with Vanilla, Forge, or NeoForge. A loader
must support the exact Minecraft release you choose. Ephervex does not
substitute a different version when a selection is unsupported. On ARM, a
Minecraft version also needs compatible native libraries; see
[installation](/install).

Fabric, Quilt, Minecraft snapshots, pre-releases, and release candidates are
not supported. Windows and macOS are not supported. Prism and MultiMC exports
are recognized but refused. The desktop interface is currently English only.

## Current limitations

- CurseForge features need an API key, either supplied by the release or
  configured in Ephervex. Pack files whose authors disable third-party
  downloads must be downloaded manually.
- Resource packs, shader packs, and datapacks in imported packs are not yet
  preserved.
- Quitting Ephervex stops running clients and servers.
- Avoid simultaneous mod changes on the same instance or server, including
  changes during an active mod isolation session.
- Session-only Microsoft sign-in does not retain credentials. Persistent
  credential storage needs a working Secret Service provider, such as GNOME
  Keyring or KWallet.
